## 🌍 1. Air Quality Prediction Using Machine Learning

An end-to-end machine learning project that predicts carbon monoxide (CO) concentration using environmental and sensor measurements from the UCI Air Quality Dataset.

### Key Features

- Data preprocessing and missing-value handling.
- Exploratory Data Analysis (EDA).
- Feature engineering with cyclical time features.
- Regression model development and comparison.
- Hyperparameter tuning using RandomizedSearchCV.
- Chronological train-test splitting.
- Interactive multi-page Streamlit application.
- Model insights and prediction visualization.

### Model Performance

**Tuned Random Forest Regressor**

| Evaluation Metric | Test Result |
|:---|---:|
| MAE | **0.3149** |
| MSE | **0.2177** |
| RMSE | **0.4666** |
| R² Score | **0.8713** |

### Technologies Used

`Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib` `Seaborn` `Plotly` `Streamlit`

## 🔬 3. Undergraduate Thesis Research

### Improving Short-Form Video Virality Prediction Through Multimodal Incongruency Detection

My approved undergraduate thesis explores whether detecting incongruency across different modalities of short-form videos can improve virality prediction.

### Research Focus

- Developing a machine learning-based Incongruency Detector.
- Exploring Vision Transformer (ViT)-based visual representations.
- Investigating multimodal information in short-form videos.
- Comparing baseline virality prediction with an incongruency-enhanced approach.
- Evaluating prediction performance using regression metrics.
